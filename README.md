Nightdrive is an offline cover-art studio that turns personal photos into a graphic, multi-panel city poster. Choose an editorial composition and color story, click a panel to assign a photo, drag to position it, and tune crop and zoom. Download a full-resolution PNG in landscape, square, or portrait. The skyline, palm silhouettes, sunburst, border treatment and typographic composition are drawn in Canvas; no game artwork or logos are used. The included sample photos come from the competition kit. Anton and Space Grotesk are bundled under the SIL Open Font License in `app/fonts/`.

## Run it

```sh
node serve.ts --port 8097
# Open http://localhost:8097/ in a desktop browser.
# Or serve app/ with any static file server; no build step or network access is needed.
```

To generate the competition output with Node 22: `MAKEFUN_OUTPUT_DIR=out node main.ts`.
